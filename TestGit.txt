Practising git command via cmd 

##create a new repository on the command line
echo "# DSATutorials" >> README.md
git init
git add README.md
git commit -m "first commit"
git branch -M main
git remote add origin https://github.com/siva5499/DSATutorials.git
git push -u origin main

##push an existing repository from the command line
git remote add origin https://github.com/siva5499/DSATutorials.git
git branch -M main
git push -u origin main

Above a important basic commands everyone should known
